# 刷题打卡记（Study Check-in Tracker）

一款用于公考 / 考研 / 考证等备考场景的微信小程序，帮助用户记录每日刷题打卡、可视化学习数据，并通过「学习搭子」机制增加坚持下去的动力。已通过微信 ICP 备案与官方审核，正式发布 v1.0.0。

## ✨ 功能特性

- **每日打卡记录**：支持自定义科目 / 学习计划，记录当天刷题数、正确数，自动计算正确率
- **多维数据可视化**：
  - 热力图（近一年打卡强度，类 GitHub Contributions 风格）
  - 趋势图 / 雷达图，展示各科目学习分布与变化趋势
  - 月度、累计数据统计
- **规则引擎点评系统**：基于连续打卡天数、正确率、里程碑等规则，自动生成个性化鼓励文案（新手期、连续 7/14/30 天等多套模板库）
- **打卡分享海报**：一键生成带小程序码的打卡战绩海报，支持保存 / 分享给好友或朋友圈
- **学习搭子系统**：基于邀请码添加学习伙伴，排行榜对比打卡数据，互相监督
- **打卡提醒**：基于微信订阅消息，每日定时提醒未打卡用户
- **多学习计划管理**：支持创建 / 切换 / 删除多套学习计划，各计划数据独立统计
- **离线优先体验**：打卡记录本地乐观更新 + 后台同步队列，弱网环境下也能秒开秒存，同步失败自动重试

## 🛠 技术栈

- **前端**：微信小程序原生框架（WXML / WXSS / JS），无第三方 UI 库
- **后端**：微信云开发（CloudBase）—— 云函数 + 云数据库，无需自建服务器
- **架构特点**：
  - 本地缓存 + 云端同步的双写策略，降低弱网/云函数冷启动带来的等待感
  - 纯函数式的规则引擎（`utils/evaluate.js`）驱动点评文案生成，逻辑与展示解耦
  - 待同步队列（`utils/syncQueue.js`）实现打卡记录的乐观更新与失败重试

```
daka-miniprogram/
├── app.js / app.json / app.wxss    # 小程序入口与全局配置

│   ├── data/            # 数据可视化页（Tab：热力图/趋势图/雷达图）

│   ├── partner-rank/      # 学习搭子排行榜
│   └── add-partner/       # 添加学习搭子（邀请码）
├── utils/
│   ├── storage.js        # 本地存储封装
│   ├── evaluate.js       # 规则引擎：打卡点评文案生成
│   ├── partner.js        # 学习搭子 / 邀请码逻辑

                            # 学习搭子、订阅消息提醒、数据统计等接口
```

## 🚀 本地运行

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 用开发者工具打开本项目根目录（`daka-miniprogram/`）
3. 在微信云开发控制台创建一个云环境，并将云环境 ID 配置到 `app.js` 中
4. 依次右键 `cloudfunctions/` 下的每个云函数目录，选择「上传并部署：云端安装依赖」
5. 编译预览即可在开发者工具或真机上体验

> 若需要打卡提醒功能，需在微信公众平台自行申请订阅消息模板，并将模板 ID 配置到 `utils/partner.js` 中。
